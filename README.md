# 🍕 SQL Project: Pizza Sales Analysis
## 📌 Project Overview
This project focuses on analyzing a pizza sales dataset using SQL to extract meaningful business insights and support data-driven decision-making.
The objective of this project is to simulate a real-world Data Analyst workflow, where raw transactional data is transformed into actionable insights by answering key business questions using SQL queries.

### 🎯 Objectives

- Analyze overall sales performance

- Understand customer ordering patterns

- Identify top-performing pizzas by quantity and revenue

- Evaluate category-wise and time-based sales trends

- Strengthen practical SQL querying skills

### 🗂️ Dataset Description

The dataset consists of multiple related tables representing a pizza business:

- Orders – Order date and time

- Order_Details – Quantity of pizzas ordered

- Pizzas – Pizza size and price

- Pizza_Types – Pizza name and category

These tables are connected using primary and foreign keys to form a relational database schema (refer to schema diagram in the project PDF).

### 🛠️ Tools & Technologies Used

- SQL (MySQL)

- SQL concepts applied:

- JOINs (INNER JOIN)

- Aggregate functions (SUM, COUNT, AVG)

- GROUP BY & ORDER BY

- Subqueries

- Window functions (RANK, OVER)

- Date & time analysis

### 📊 Business Questions Answered

Some of the key questions explored in this project include:

- Total number of orders placed

- Total revenue generated from pizza sales

- Highest-priced pizza

- Most commonly ordered pizza size

- Top 5 most ordered pizza types

- Category-wise quantity and revenue distribution

- Hourly order distribution

- Average number of pizzas ordered per day

- Cumulative revenue growth over time

- Top-performing pizzas by revenue within each category

- Each question is answered using clear, well-structured SQL queries, with results included in the project presentation.

### 🔍 Key Insights

- Certain pizza sizes dominate customer preferences

- A small number of pizza types contribute significantly to total revenue

- Order volumes vary noticeably by hour of the day

- Revenue growth follows consistent daily patterns

- Category-wise analysis helps identify high-impact product segments

- These insights demonstrate how SQL can directly support business strategy and operational decisions.
